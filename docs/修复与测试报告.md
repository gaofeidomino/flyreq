验证日期：2026-10-14。项目位于 `/Users/gaofei/work/flyreq-review`，审查起点 `186fc157ece712a5c4ce953bb90894ee1e539048`。

## 修复内容

1. 业务认证信息与 baseURL 在缓存和幂等计算之前补齐，避免不同用户或服务地址复用结果；显式小写 authorization 头不再被默认令牌覆盖，静态令牌可替换旧 getter。
2. 默认缓存键使用完整请求身份。幂等序列化保留类型、结构、服务地址、日期及二进制内容；循环与无法可靠编码的正文明确报错，支持自定义键。
3. Fetch 同时处理外部取消和超时，并清理监听器与定时器；HEAD、204、205 正确处理空响应；已经解析的 JSON 字符串不再被重复解析。
4. CLI 生成 POST/PUT/PATCH 分页代码时使用正确的正文与 options 参数位置，路径参数经过编码；移除与 ES2020 不兼容的 replaceAll 调用。
5. 请求合并延续到异步缓存写入结束，避免持久化存储写入期间重复发送。
6. 重试/并发数量进行范围校验；取消不再重试，重试等待期可立即取消，已取消的缓存请求拒绝执行；串行/并发任务执行前检查取消。
7. beforeRequest 钩子异常进入 error 通知链。修复严格类型检查中的存储对象判空与配置类型推断错误。
